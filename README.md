### What I work on

- **Gameplay mechanics** across ten genres — hyper-casual, mid-core action, idle and idle RPG,
  match-3, merge, card battler, tower defense, turn-based strategy, tycoon sim, runner.
- **Meta and monetisation** — shops and offer storefronts, subscriptions, AFK rewards,
  daily and weekly offers, boosters, rewarded-ad payouts, progression.
- **WebGL ports** to Poki and Yandex Games — platform SDK facades, reworking monetisation
  for the browser, passing platform moderation.
- **Build optimisation** — cutting build size and load time: IL2CPP settings, stripping,
  Addressables groups, import settings.
- **Playable ads** — 40+ builds for 10 titles on Unity Playworks, recreated from art alone.

Outside work I build PC projects and reusable tooling, and I am currently learning
client-server and multiplayer.

### How I work with AI

I treat AI as an engineering tool rather than a chat window. I build and maintain a library
of specialised agents, skills and knowledge bases on top of Claude Code, wired into the Unity
Editor over MCP — scaffolding project architecture, integrating mechanics, ECS code review,
platform ports, game economy modelling.

Every project carries its own `CLAUDE.md` with the rules those agents work under. Generated
code goes through the same review as anything I write by hand; if I cannot defend it, it does
not ship.
